How this works

  • Click Open video… to load any clip your browser can decode (MP4/H.264, WebM, …). It plays, and every displayed frame is downscaled, sent to the Cortex C++ engine compiled to WebAssembly, filtered, and drawn back to the canvas — in real time. Nothing is uploaded anywhere; it all runs locally.
  • Drag Brightness / Contrast / Saturation / Blur while the video plays — the picture changes instantly.
  • The spinner top-left is animated by requestAnimationFrame. As long as it keeps spinning, the main thread is free.
  • Turn on Cortex cooperative engine and crank Blur: the heavy per-frame filtering is split into row-bands that Yield() via cortex::tiny_fiber, so even an expensive filter never freezes the page — the video just processes as fast as the engine can.
  • Use sample clip returns to a built-in procedurally-generated animation, so the editor is usable with no file at all.
