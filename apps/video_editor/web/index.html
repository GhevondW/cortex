How to read this demo

  • The 180-frame source "video" is generated by C++ at startup — a colorful animated gradient with three orbiting discs. Use the timeline to scrub through it.
  • The spinner in the top-left animates via requestAnimationFrame. If it freezes, the main thread is blocked.
  • Apply (blocking) runs the filter chain synchronously. The spinner stops, the timeline goes unresponsive, the progress bar jumps to 100% only after the work is done.
  • Apply (cooperative) runs the same work via cortex::tiny_fiber — workers Yield() between frames, the spinner keeps spinning, and the timeline stays draggable.
  • Cancel calls Scheduler::Stop(); workers catch SchedulerStoppingError and exit cleanly.
  • A / B toggles between the source frame and the edited output.
