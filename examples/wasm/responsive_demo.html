Responsive C++

A Mandelbrot explorer rendered by C++ compiled to WebAssembly. The renderer is ordinary C++ with one CheckPoint() per row. Run as Cortex fibers, it shares the main thread fairly: keep clicking, typing and watching the pulse while it works. Switch to Plain call to run the very same function directly, and watch the page freeze.

Click to zoom in · Shift-click or right-click to zoom out · clicking during a render cancels it.

The renderer: plain C++

void RenderRows(const View& view, int y0, int y1, ...) {
    for (int y = y0; y < y1; ++y) {
        for (int x = 0; x < kWidth; ++x) {
            // escape-time iteration for one pixel
        }
        tf::CheckPoint(); // one check per row is plenty
    }
}

In a fiber, CheckPoint() yields once its 2 ms slice is used up. Called directly, it does nothing, which is what "Plain call" does.

The controller: a fiber

for (const Command& command : commands) { // Channel fed by clicks
    if (render) {
        render->Cancel(); // stale view: stop its bands
        render.reset();
    }
    render.emplace(tf::Spawn([=] { RenderView(id, view); }));
}

Each render spawns four band fibers and WaitAlls them. The palette is loaded with cortex::web::Await(fetch(...)), and the tour sleeps with tf::SleepFor. js/cortex.mjs drives it all in 8 ms slices.
